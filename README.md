# calculadora-em-C


## Visão geral
Este projeto consiste no desenvolvimento de uma calculadora simples utilizando a linguagem C. O programa permite que o usuário informe dois números e escolha uma operação matemática para realizar o cálculo.
A calculadora oferece as operações básicas de soma, subtração, multiplicação e divisão. O projeto foi desenvolvido como atividade prática de programação, com foco nos fundamentos da linguagem C.

## Objetivos
- Praticar a declaração e a utilização de variáveis.
- Receber dados digitados pelo usuário com `scanf()`.
- Exibir mensagens e resultados utilizando `printf()`.
- Utilizar estruturas de seleção com `switch` e `case`.
- Realizar operações matemáticas básicas.
- Aplicar estruturas condicionais com `if` e `else`.
- Tratar a tentativa de divisão por zero.

## Tecnologias utilizadas
- **Linguagem:** C
- **Biblioteca:** `stdio.h`
- **Entrada de dados:** `scanf()`
- **Saída de dados:** `printf()`
- **Estruturas de controle:** `switch`, `case`, `if` e `else`

## Funcionalidades
- Solicitação de dois números ao usuário.
- Menu interativo para escolha da operação matemática.
- Cálculo de soma.
- Cálculo de subtração.
- Cálculo de multiplicação.
- Cálculo de divisão.
- Verificação de divisão por zero.
- Mensagem de erro para operações inexistentes.

## Pré-requisitos
- Compilador da linguagem C, como GCC.
- Editor de código, como Visual Studio Code, ou outro ambiente de desenvolvimento compatível.

## Como executar
1. Salve o código em um arquivo chamado `calculadora.c`.
2. Abra um terminal na pasta em que o arquivo foi salvo.
3. Compile o programa utilizando o GCC:
```bash
gcc calculadora.c -o calculadora
```
4. Execute o programa.
No Windows:
```bash
calculadora.exe
```
No Linux:
```bash
./calculadora
```

## Exemplo de utilização
```text
Digite o primeiro numero: 10
Digite o segundo numero: 5
1 - Soma
2 - Subtracao
3 - Multiplicacao
4 - Divisao
Escolha a operacao: 4
Resultado: 2.00
```
